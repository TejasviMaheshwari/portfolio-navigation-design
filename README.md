# Personal Portfolio Website

A simple multi-page personal portfolio website created using **HTML and CSS**. This project demonstrates website navigation, CSS styling, gradient backgrounds, Flexbox layout, and hover animations.

## 📌 Features

* Multi-page website structure
* Navigation links for Home, About Us, Projects, Achievements, and Contact Us
* Colorful gradient backgrounds
* Responsive viewport configuration
* Flexbox-based navigation layout
* Rounded navigation bar
* Hover animations on navigation links

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
personal-portfolio-website/
│
├── index(3).html
├── About.html
├── project.html
├── Achivement.html
├── contact.html
└── README.md
```

**Note:** Rename `index(3).html` to `index.html` for easier GitHub Pages deployment. Update any links if you rename other files.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Use the navigation bar to explore the website pages.

## 🎯 Learning Objectives

* Understanding HTML page structure
* Applying CSS styles and gradients
* Using Flexbox for alignment and spacing
* Creating navigation links between pages
* Implementing hover effects and transitions
